# Privacy

[فارسی](docs/privacy.fa.md) · Applies to this 3.7.7 source distribution.

**On this computer.** Chrome local extension storage holds settings, Gemini and OpenAI-compatible keys, the bridge token, provider/model discovery, usage counters, translation-memory terms and cached translations. The persistent translation cache can contain source-related metadata and translated text; hashed cache keys do not encrypt the values. Its current limit is 20,000 entries, with pruning toward 16,000. An in-memory layer also exists. Subtitle workshop projects, imported content and edits use IndexedDB. The optional bridge can create local job folders, intermediate media and downloaded model caches. These are user data, not part of the distribution.

**Sent to services.** The chosen translation provider receives requested text and relevant prompts, glossary, memory hints and context. AI image operations may send image bytes. Speech services receive text; Gemini Live receives captured audio; transcription can run locally through Whisper when configured. Google/Bing web translation and Bing speech use their respective online endpoints. OpenAI-compatible requests go to the base URL you configure; this can be a remote third party or a local server. Provider-side context caching, if enabled, creates reusable prompt content at Gemini. Providers control their own retention, terms and account billing.

**Local does not always mean offline.** The bridge listens on `127.0.0.1`, default port 8765. Its health route exposes capability and installation hints without a token; other operations require the pairing token and check origins. Edge TTS sends speech text to Microsoft's online service. Package update checks contact PyPI. Downloading transcription/voice models contacts their hosts. External manga software can use its own remote services and credentials. Screen OCR processes the capture locally, but the extracted text is sent to the selected translator.

**Keys and backups.** Keys are in Chrome's local extension storage, not an encrypted vault and not Chrome sync storage. The companion stores its token in `bridge/token.txt`. Settings export excludes credentials by default; enabling key export includes credentials, including the bridge token. Even a key-free backup can include sensitive memory, prompts or configuration. The settings backup does not back up the separate workshop project database. Keep backups and the bridge folder private.

**Developer collection.** This release contains no developer telemetry/analytics endpoint, advertising or automatic upload of local statistics to the developer. The local usage counters help manage quotas. Content still leaves the device when you use an online feature, and websites/providers see normal network metadata. Support files you choose to send are outside this local-only statistics behavior.

**Permissions and removal.** Storage supports settings/projects/cache; unlimitedStorage supports larger local data; scripting, activeTab and optional host permissions allow requested site tools; contextMenus adds actions. Gemini and X image hosts are declared host permissions. Clear cache or memory using the corresponding controls. Export important workshop work before deleting it. Chrome removal/clearing extension data can remove browser storage but does not erase bridge jobs, downloaded models or exported backups from disk; delete those separately when no longer needed.
