# ترجمان ۳.۷.۷

[English](README.md) · [راهنمای کامل](docs/guide.fa.md) · [حریم خصوصی](docs/privacy.fa.md)

[دانلود نسخهٔ ۳.۷.۷](https://github.com/gvgergrh1386-svg/tarjoman/releases/tag/v3.7.7) · [گزارش اشکال](https://github.com/gvgergrh1386-svg/tarjoman/issues) · [آزمون‌های خودکار](https://github.com/gvgergrh1386-svg/tarjoman/actions)

ترجمان افزونهٔ Manifest V3 کروم برای ترجمهٔ پست، صفحه، تصویر و زیرنویس است. رابط فارسی و انگلیسی دارد؛ زبان رابط، زبان مقصد ترجمه و قالب‌های منطقه‌ای را جداگانه انتخاب می‌کنید.

## قابلیت‌ها

- ترجمهٔ X و توییتر با کش پایدار، اشتراک درخواست‌های یکسان و جلوگیری از نمایش پاسخ منسوخ.
- ترجمهٔ صفحه و متن انتخاب‌شده، خلاصه، ترجمهٔ متن تصویر و خواندن متن.
- زیرنویس و دوبلهٔ یوتیوب و ابزارهای اختیاری زیرنویس و صدا برای پخش‌کننده‌های دیگر وب.
- کارگاه زیرنویس با ورود فایل، ویرایش ترجمه، قفل ردیف، ذخیرهٔ پروژه روی دستگاه و خروجی.
- ابزار مانگا با پل محلی اختیاری و مترجم جداگانه.
- پشتیبانی از Gemini، سرویس‌های سازگار با OpenAI، Google Translate و Bing؛ حافظهٔ ترجمه و ظاهر قابل تنظیم.

دسترسی به قابلیت‌ها به سرویس انتخابی، مجوز دسترسی، وجود زیرنویس و ابزارهای محلی بستگی دارد. حساب، کلید سرویس، مدل صدا و نرم‌افزار مانگا همراه این بسته نیست. سهمیه و دسترس‌پذیری سرویس‌ها تضمین‌شده نیست.

## نصب

۱. فایل [Tarjoman-3.7.7-Chrome.zip](https://github.com/gvgergrh1386-svg/tarjoman/releases/download/v3.7.7/Tarjoman-3.7.7-Chrome.zip) را دانلود و در پوشه‌ای دائمی استخراج کنید.

۲. در `chrome://extensions` حالت **Developer mode** را روشن کنید، **Load unpacked** را بزنید و پوشهٔ دارای `manifest.json` را انتخاب کنید.

۳. از تنظیمات موتور ترجمه، سرویس را انتخاب کنید و در صورت نیاز کلید خودتان را وارد کنید. دسترسی اختیاری به سایت‌ها را برای قابلیت مورد نیاز بدهید.

۴. در **زبان و منطقه**، حالت خودکار، فارسی یا انگلیسی را انتخاب کنید. مقصد ترجمه به‌صورت پیش‌فرض فارسی است.

حداقل نسخهٔ اعلام‌شدهٔ کروم ۱۱۶ است؛ آزمون انتشار با کروم دسکتاپ فعلی انجام می‌شود. صفحه‌های داخلی مرورگر و صفحه‌های محدود فروشگاه قابل ترجمه نیستند. این بسته نصب دستی دسکتاپ دارد؛ انتشار فروشگاهی مرحله‌ای جداست.

برای ارتقای نصب دستی، ابتدا پشتیبان خصوصی بگیرید، فایل‌های **همان پوشهٔ قبلی** را جایگزین کنید و دکمهٔ **Reload** کارت افزونه را بزنید. مسیر جدید ممکن است شناسه و فضای ذخیره‌سازی جدا بسازد. افزونهٔ قبلی را برای ارتقا حذف نکنید. جزئیات در [راهنما](docs/guide.fa.md) آمده است.

## زبان و منطقه

نصب تازه از زبان پشتیبانی‌شدهٔ مرورگر پیروی می‌کند و در نبود آن انگلیسی نشان می‌دهد. تنظیمات قدیمی، فارسی، تقویم شمسی، ارقام فارسی و ساعت تهران را حفظ می‌کنند. تغییر زبان رابط کش ترجمه یا محتوای ذخیره‌شده را تغییر نمی‌دهد. زبان مبدأ خودکار تشخیص داده می‌شود. مقصد را از پیشنهادهای زبان انتخاب کنید یا کدی مانند `fr`، `ja`، `ar`، `hi` یا `pt-BR` وارد کنید. ایکس، کادر نوشتن، صفحه/انتخاب متن، تصویر، خلاصه، ویدیوی وب، فایل و مانگا کنترل مقصد مستقل دارند؛ `inherit` یعنی پیروی از مقصد عمومی. یوتیوب و پروژه‌های کارگاه نیز مقصد خود را دارند. کش زبان‌های مقصد جداست. پشتیبانی و کیفیت به سرویس ترجمه، OCR و گفتار انتخابی بستگی دارد؛ همهٔ سرویس‌ها الزاماً همهٔ زبان‌ها را پشتیبانی نمی‌کنند.

## توسعه

پایتون ۳.۱۰ یا جدیدتر، Node.js نسخهٔ ۲۰ یا جدیدتر و برای آزمون مرورگر، Chrome لازم است. اجرای خود افزونه به نصب بسته‌های جاوااسکریپت یا چارچوب رابط نیاز ندارد.

```sh
npm ci
python tools/build_i18n.py --check
node tools/check_i18n.cjs
python tools/test_all.py
python tools/test_all.py --browser
python tools/build_release.py
python tools/verify_release.py
```

ساخت با فهرست صریح فایل‌ها، مشخصات ثابت ZIP و هش SHA-256 انجام می‌شود. [راهنمای مشارکت فارسی](docs/contributing.fa.md)، [معماری](docs/architecture.md)، [تغییرات](CHANGELOG.md)، [گزارش انتشار](docs/release-3.7.7.fa.md).
